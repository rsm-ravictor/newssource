{#- Preview harness for the digest email. The iframe never moves in the DOM when you toggle — only the surrounding chrome and the frame dimensions change — so the email is not reloaded and its scroll position survives the switch. The email is embedded via srcdoc so this page works from file:// with no server and no fetch (which file:// would block).
